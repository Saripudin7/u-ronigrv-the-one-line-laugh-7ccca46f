# The One-Line Laugh

One original one-liner (76 characters, a single sentence) for the make.fun
bounty [u-ronigrv-the-one-line-laugh-7ccca46f](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f):
a smart speaker asked for a joke answers with the one thing you never wanted
read out loud — your search history.

## How to run

```sh
python3 main.py
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Python standard library only, no network access, deterministic output.
